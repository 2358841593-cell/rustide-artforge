## 步骤

1. **读照片** → 填下面「照片层」的槽位
2. **选职业** → 查 §职业表，`随身三件 / 穿什么 / 杂物主类` 直接抄
3. **查重** → `references/world/cast.md`：

   | 项 | 规则 |
   |---|---|
   | **随身三件** | **不能重**。这是防同质化的核心 |
   | **主强调色** | 一组内不重（七个可选，见 §配色） |
   | 杂物主类 | **可以重**（只有六类），但具体物件要不同 |
   | 职业 | 可以重（一个世界里多个炉工很正常），但那就更要靠随身三件区分 |
4. **填模板**（§模板，结构一个字不改）
5. **检查** `python3 checklists/check.py prompt.txt`
6. **出图**：附 `assets/refs-cel/27-opening-cast-lineup.png`（比例锚，永不换）
   ＋ §上墨锚表 里按**招牌特征**选的那一张。**一次出 2–3 张，目视选片**
7. **验收** `python3 checklists/check.py 出图.png`，看标尺图判头身比
8. **出另外四张资产**（三视图 / 表情表 / 动作表 / 色卡，见 §一个角色 = 五张图）
9. 成品存 `角色成品/`，**提示词同名 .txt 一起存**，登记进 `cast.md`

## 一个角色 = 五张图（角色说明书）

调研传统动画 model sheet 与 AI 漫剧一致性做法，稳定一个角色需要这五张。
**每张都是一张图里排多格 —— 同一次生成，细节天然一致。分开出必然漂移。**

| # | 资产 | 模板 | 尺寸 | 参考图 | 内容 |
|---|---|---|---|---|---|
| 1 | **立绘** | `GOLD-from-scratch.txt` | 1024×1536 | `27-cast-lineup` + 上墨锚 | 正面全身 |
| 2 | **三视图** | `TURNAROUND.txt` | 1536×1024 | **该角色的立绘** | 正 / ¾ / 侧 / 背，同一地平线等高 |
| 3 | **表情表** | `EXPRESSIONS.txt` | 1024×1536 | 同上 | 三列两行：平静/开心/难过/生气/惊讶/疑惑 |
| 4 | **动作表** | `POSES.txt` | 1536×1024 | 同上 | 站立 / 行走 / 举手 / 蹲低 |
| 5 | **色卡** | `COLORKEY.txt` | 1536×1024 | 同上 | 头肩像 + 九个色卡（带 HEX 标注） |

> **①出完之后，②③④⑤ 的参考图一律用①那张立绘**，不要传官方参考图。
> 官方图只在出①时用。

### 为什么是这五张

> AI 漫剧的核心问题：*"跳过参考表，后续每次生成都在让模型现编——
> 夹克背面、侧脸、靴子、表情范围、配色。"*

- **三视图**补的是「背面和侧面长什么样」——这是最容易被现编的部分
- **表情表**补的是「情绪范围」
- **动作表**补的是「动起来体块怎么变」
- **色卡**补的是「配色的准确数值」，而且是**机器可读**的

传统动画的完整 model sheet 还含结构表（辅助线）和口型表（phonemes）。
要做动画再补；做漫剧/立绘这五张够了。

### 一致性靠什么

每个模板里都有一段 **`SAME PERSON EVERY TIME`**：
把不变的东西逐项点名（发色发型 / 遮挡 / 服装 / 招牌特征 / 随身三件），
再明确**只允许什么变**（表情表只变眼眉嘴，动作表只变姿势和衣摆）。

### 已知缺陷

网格类资产（表情表）偶尔会在单格里画出**双瞳孔**之类的小错。
单格分辨率不够时容易发生。**出图后逐格看一眼**，有问题重出整张（不要单独修一格）。

## 三条最容易犯的错

1. **`short stocky body` / `five heads tall` 是画法常量**，任何角色都要写。
   改成 `slim` 必出 7 头身。体型差异只用 §体块 表达。
2. **禁用词** `anime` / `black` / `chibi` / `realistic` / `muted` / `dusty`，**哪怕在否定句里**。
   **零否定词**——生图模型没有 negative 通道。
3. **必须是生成模式**。`edit target` / `retain the` / `change only` 这类措辞会被 `check.py` 拦下。
   编辑链连改 8 次，头身比从 5 退到 7。

## 两阶段闸门

**①立绘合格了，才出②③④⑤。** 立绘是后四张的参考图——立绘不对，四张全废。

立绘的合格线：`check.py` 两项 + 标尺图头身比 + **目视对照照片**（特征抓到没有）。

### 实测踩过的两个坑

| 坑 | 修法 |
|---|---|
| 编号被画到**画布角落**当标签，不在衣服上 | 模板改成 `The number "{编号}" is stencilled onto the garment itself, on the chest or the back` |
| 色卡有时**只有名称没有 HEX** | 模板改成明确要求「第一行名称、第二行完整六位 hex 带 # 号」 |

> 这两个都是模板**没说清楚放在哪 / 长什么样**造成的，不是模型的问题。
> **凡是"应该出现"的东西，都要写明「出现在哪里」。**
