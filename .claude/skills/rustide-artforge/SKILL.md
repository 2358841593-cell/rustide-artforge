# RUSTIDE ARTFORGE

把真人照片锻成《锈汛》世界的居民。**产物是提示词，不是图。**

## 做法

1. **传参考图**：比例锚固定 `assets/refs-cel/27-opening-cast-lineup.png`；
   **上墨锚按角色性别/年龄换**——这一条很重要：

   | 角色 | 上墨锚 |
   |---|---|
   | 成年男性 | `06-john-early-portrait.png` |
   | **成年女性** | **`09-isabel-early-portrait.png`** |
   | 少年 / 中性 | `08-alva-early-portrait.png` |
   | 老人 | `13-hoffman-early-portrait.png` |
   | 儿童 | `07-sam-early-portrait.png` |

   ⚠️ **实测**：上墨锚一直固定用约翰（男性），结果两个女性照片出来全是中性偏男。
   模板里当时还写死了 `he` / `his` 三处，已清。

2. **抄模板**：`templates/GOLD-from-scratch.txt` —— 它和 `GOLD-v26-original.txt`
   **八段结构逐字一致**，只把角色特定的值换成了占位符。**结构一个字都不要改。**

3. **必须是生成模式**（从照片直出）。
   ⚠️ **两张认可的成品都是生成模式出的**，而且都是在我给了编辑指令之后、
   执行方**抛开编辑指令自己重写生成模式提示词**才出来的。
   编辑模式（"以上一张图为编辑目标"）连续用会累积漂移——实测连改 8 次，比例从 5 头身退到 7。

4. **先查重再填**：翻 `references/world/cast.md`，新角色的**职业 / 随身三件 / 主强调色 / 母题组合**
   都不能和已有角色重。⚠️ 实测六人一组时**主强调色撞了三次**（汛红），一排站开明显同质。
   主强调色是记忆点，**一组里绝不能重**。

5. **填内容**：职业与随身三件 → `references/world/professions.md`；
   小传取材 → `references/world/daily-life.md`；查重 → `references/world/cast.md`；
   照片怎么读 → `references/photo-to-character.md`。

6. **检查**：`python3 checklists/check.py prompt.txt`

6. **出图**，存进 `角色成品/`，**提示词同名 `.txt` 一起存**。

8. **看结果**：`python3 checklists/check.py 出图.png`（平涂率、色密度 + 标尺图）

## 八条规矩

1. **生成模式是默认。** 从照片直出完整提示词。
   编辑模式（"以上一张图为编辑目标，其余保持不变"）**只允许单次单点，绝不连续**——
   实测连续编辑 8 次，头身比从 5 退回 7，画风崩坏全部作废。**那是手动修图，不是 skill。**
2. **`short stocky body, five heads tall` 是画法常量，任何角色都要写。**
   实测：改成 `slim` 必出 7 头身（v29–v36、后续两个角色，无一例外）。
   `stocky` 锚的是**压缩画法**，不是胖瘦；`slim` 会和 `short` 打架把人拉长。
   照片的胖瘦体现在**脸型和四肢粗细**上。
3. **生理域只能放大照片里已有的。** 五官、脸型、四肢粗细、肤色 —— 照片里没有的一个都不许加，
   哪怕它是这个 IP 的经典母题（红鼻头就是这么被从参考图抄进来的）。
   **装扮域**（服装、配饰、道具、护目镜、义肢）随便夸张。
4. **夸张要写成模型能自检的线性关系。**
   `the sleeve is as wide as his chest` ✅ / `放大到头部 1.5 倍` ❌（面积模型算不出来）。
   这和压住比例用的 `head as tall as boots` 是同一个机制——**抽象形容词一律无效**。
   而且要 **3 个夸张点**，不是 1 个：参考图里所罗门有莫西干 + 异色镜片 + 破袖三处。
5. **世界观靠母题重复显形，不靠设定文字。**
   每个角色至少带 **2 个**《锈汛》专属母题（锈斑 / 蜡封 / 闲置的护具 / 旧世铭牌 / 裸露走线），
   清单见 `references/world/00-core.md` §7b，那里也列了三条**通用蒸汽朋克反面清单**。
   **一个角色显不出世界观，一组角色共用母题才行。**
6. **一次只动一个旋钮。** 改多处就不知道是哪个起的作用。改体型时把"瘦"和"五头身"写在同一句。
7. **单轮最多 3 版。** 三版没到位说明措辞有问题，回去改词，不要靠重抽。
   **人眼选片**——实测出现过"指标更合格但更难看"。
8. **服装从照片来。** 照片穿什么就改造什么，不要套固定工装。

## 硬检查（`check.py` 会跑）

**出图前 · 四条**
- **生成式保证**：出现 `edit target` / `keep its` / `retain the` / `change only` / `preserve its`
  一律拦下。**本 skill 是生成类**——从照片直出，绝不拿上一张图当底改。
  实测：编辑链连改 8 次，头身比从 5 头身退到 7，画风崩坏全部作废。
- **禁用词** `anime` / `black` / `chibi` / `realistic` / `muted` / `dusty`，**哪怕在否定句里**
- **零否定词** —— 生图模型没有 negative 通道，否定≈把概念念一遍
- **PHOTO-LOCK 段** —— 写明「参考图只提供画法，不提供五官」

**出图后 · 两条（量"油"）**
- **平涂率 ≥15%**（与右邻像素完全同色的比例。官方 15.4–25.0，出图曾低到 **2.2**）
- **色密度 ≤2600**（每万像素独立色数。官方 1188–2483，出图曾高到 **3528**）

> **平涂率是"油"的量化形态**：官方图有大片真正的平色块，AI 出图几乎每个像素都和邻居差一点点。
> **这两条不是靠重抽能解决的，只能改措辞**：
> 用 `cel-painted` / `flat colour fields`，**不要用 `cel-shaded`** ——
> 后者在 CG 语境里指**三维卡通渲染**，会把图往"油"里带。

## 参考数值

`references/metrics.md` 有八项从官方参考图实测的区间（线宽、暗部、彩度、暖色、曲率等）。
**它们是诊断用的参考值，不是门禁。** 觉得图不对时去查，不要拿它当目标刷。
