## 设计原则

参考游戏设定集的通行做法：**关键物件、大事件、地点** —— 这三样是"故事能挂上去、
且能被对白和美术直接引用"的东西。设定文字本身不产生视觉，**这三样才产生**。

所以本设定集的重心不在世界史，而在：
- **职业档案**（决定角色带什么、穿什么、身上有什么痕迹）
- **关键物件**（能挂故事，也能直接画进画面）
- **可引用大事件**（给角色一个共同的过去，让一组角色像同一个世界的人）
