## 查重（做新角色前对一遍）

| 项 | 规则 | 为什么 |
|---|---|---|
| **随身三件** | **绝不能重** | 防同质化的核心。重了说明没认真填职业档案 |
| **主强调色** | 一组内不重 | 记忆点色，一排站开撞色最明显。七个可选 |
| 杂物主类 | 可以重 | 只有六类，14 人必然重复。但**具体物件**要不同 |
| 职业 | 可以重 | 一个世界里多个炉工很正常，靠随身三件区分 |
| 母题组合 | 尽量不重 | 五个母题两两组合十种，够用但不强求 |

> ⚠️ 早期版本要求「职业和杂物主类都不能重」，实测**做到 14 人时必然违反**——
> 六类杂物装不下 14 个角色。规则本身错了，已放宽。

## 群像配额（角色够 4 个以后开始生效）

- 每 4 个"正常"角色配 1 个明显跳脱的（机械 / 异类 / 极端造型）
- 身高要有明显阶梯（官方群像从 1:3 到 1:5.5）
- 混龄：老人 / 成人 / 少年 / 小孩 / 非人
- **细节密度要有梯度**：最多的角色应是最少的 ≥3 倍（官方跨度 珊 5 → 约翰 20）

## 杂物主类分布（14 人）

| 主类 | 谁 |
|---|---|
| 挂件类 | 钟表匠 · 教书人 |
| 线材类 | 船工 · 接线人 |
| 纸类 | 药铺 · 走商 |
| 器物类 | 画招牌的 · 乐手 · 面摊主 |
| 布类 | 拾荒者 · 炉工 |
| 徽章类 | 汛官 · 上环人 |

> **徽章类最多两个。** 徽章意味着「有组织身份」——拾荒者和乐手挂一堆徽章不合理。
> 十四人里徽章型只占两个，正是汛官和上环人这两个体制内角色。

## 实测：六人一组时踩到的坑

用四张真人照片 + 两个设计角色跑了一组，自检结果：

| 查重项 | 结果 |
|---|---|
| 职业 | ✅ 6/6 唯一 |
| 随身三件 | ✅ 6/6 唯一 |
| **主强调色** | ⚠️ **只有 3/6 唯一**——汛红 `#DD5233` 撞了三次 |
| 母题组合 | ⚠️ 5/6 唯一 |

**主强调色是记忆点，一排站开时撞色最明显。** 填内容前必须先翻本表。

调色板 §2 里够用的高饱和主强调色有七个：
汛红 `#DD5233` · 灼橙 `#EA9056` · 芥末 `#D88A3A` · 汽笛蓝 `#02758F` ·
深青 `#27777F` · 苔绿 `#5A9146` · 电紫 `#875CBD`
