# 职业档案 ·《锈汛》

> **这是设定集里最"能生图"的一册。** 选定职业后，工具、穿着、工作地、身上的味道全都自动填好。
> 每份档案的字段是固定的，为的是直接喂进出图提示词的 `CLOTHES` / `DETAIL` / `MOTIF` 三段。

字段说明：
- **在哪干活** → 决定背景与磨损来源
- **随身三件** → 直接进 `DETAIL` 段，**这是让角色互相不一样的关键**
- **穿什么** → 进 `CLOTHES` 段，是照片服装改造的方向
- **身上的痕迹** → 磨损的来历，说得出来的细节才有说服力
- **母题倾向** → 从 §视觉母题五选二时优先选哪个

## 接线人 Wirewright
| 字段 | 内容 |
|---|---|
| 在哪干活 | 釜谷厂区边缘的接线铺，或上门到工人家里 |
| 随身三件 | **卷起的检线线缆**、**一把黄铜镊子/烙铁**、**装满插头和接口盖的腰袋** |
| 穿什么 | 油布围裙式外套（防电解液）、卷到手肘的袖子、连指工作手套（常摘一只） |
| 身上的痕迹 | 前襟被电解液蚀出的浅色斑、袖口缠的绝缘胶带、指甲缝里洗不掉的油 |
| 母题倾向 | **裸露走线** + **旧世铭牌** |
| 说话方式 | 少，说的时候先说"你听" |

## 怎么用

1. 照片气质 → 选一个职业（或组合两个，例：**下岗的炉工现在拾荒**）
2. **随身三件**直接进 `DETAIL` 段 —— 这是防止"每个人衣服都一样"的核心
3. **穿什么**是照片服装的改造方向，不是替换
4. **身上的痕迹**给磨损写来历
5. **母题倾向**决定从五个母题里挑哪两个

> ⚠️ **两个角色不该有相同的"随身三件"。** 如果出现了，说明职业选重了或没认真填。
