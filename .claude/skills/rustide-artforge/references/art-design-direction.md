# 画风拆解 B ·【设计方向】

> 角度：**画的是什么、为什么这么设计**。剪影、比例、脸、服装叙事、原型、怪度配额。
> 渲染层面（线、色、光）在 `art-visual.md`。

---

## 0 · 设计哲学

风来之国的人设不靠"帅"或"美"立住，靠**三件事**：

1. **剪影可读** —— 缩到 32px 还认得出是谁
2. **衣服会讲故事** —— 每一处补丁、贴纸、缠带都在说他经历过什么
3. **允许怪** —— 荒诞不是意外，是这个世界的正常成分

我们的世界继承这三条，并加一条：
4. **锈汛给一切装备一个物理理由** —— 见 `world/00-core.md` §2

## 1 · 比例（PROPORTION）

### 1.1 头身比

| 类型 | 头身比 | 参考 |
|---|---|---|
| 成年男性 | **1 : 4.5 – 5.5** | 约翰、所罗门、威廉 |
| 成年女性 / 少年 | **1 : 5 – 5.5** | 阿尔瓦、Lee |
| 儿童 | **1 : 3.5 – 4** | 珊 |
| 老人 | **1 : 4 – 4.5**（更矮、更宽） | 霍夫曼 |
| 机器人 / 非人 | **自由**，通常更极端 | 丹尼尔（1:3，大头小身） |

> ⚠️ 不是 chibi（1:2–3），也不是写实（1:7–8）。**卡在 1:5 附近**，这是最容易跑偏的参数。

### 光写 `five heads tall` 不够 —— 要给关系锚点

实测：提示词写了 `five heads tall`，出图仍然是 **7.8 头身**。抽象比例词太弱，压不过其他 270 个词。
有效的是**模型能自己核对的关系**：

```
The head alone is as tall as the boots.
The legs from hip to floor are only two heads long.
```

### 长下摆是头身比的头号杀手

及踝长大衣会把整个人读成瘦高，无论提示词写什么。
参考图里**没有一件外套过膝**：约翰的马甲到胯，威廉的大衣到大腿中段。

> 照片是长大衣时：**保留双排扣、大翻领、披肩片这些识别特征，但把下摆截到膝盖。**
> 识别度在翻领和廓形上，不在长度上。

### 1.2 体块分配：**上重下轻**

这是最强的形式特征，看 `27-opening-cast-lineup.png` 一眼就懂：

```
       ███████        ← 头 + 头发（大、有形状）
     █████████        ← 肩 / 外套（最宽的一段，厚、方）
      ███████         ← 躯干（保持厚度）
        ███           ← 腿（明显细，几乎是两根管子）
      ██   ██         ← 靴子（重新变大、变方、变重）
```

- **外套 / 上半身是最宽的一段**，肩线要方要厚
- **腿细**，接近圆柱，不做肌肉结构
- **靴子大而方**，是全身第二大的"块"
- **手**：连指块 / 露指 / 缠布 / 爪 —— **随意，不要硬性要求**
  > ⚠️ 早期版本把"连指块"当成铁律，结果 v8–v12 五个版本全在改手。
  > 实际核对八张官方参考：珊、丹尼尔、威廉、霍夫曼**都露指**，连指块只有 3–4/8。
  > 连指块是个好用的简化手段，**不是这套画风的判据**。

### 1.3a 压倒性元素（硬性）⚠️ 「没有设计感」的根因

看用户挑出的三张参考图，共同点极其明确：

| 角色 | 压倒性元素 | 占比 |
|---|---|---|
| 伊莎贝尔 `09` | **巨大的白发块**，比身体还宽，盖住半个人 | ≈ 头部面积 3 倍 |
| 约翰 `06` | **黑胡子楔形**盖住整个下半脸 + 墨镜盖住眼睛 | ≈ 头部面积 1.5 倍 |
| 所罗门 `10` | **青色莫西干** + **红蓝异色护目镜** | ≈ 头部面积 1.5 倍 |

**规则：每个角色必须有一个造型元素，面积 ≥ 头部的 1.5 倍，并明显打破人体轮廓。**

不是"加个呆毛"那种程度。是**大到会改变剪影读法**的程度。

### 1.3b 脸必须被遮挡（硬性）

**三张参考图，三张脸都被遮住了**——约翰是墨镜+胡子，所罗门是护目镜，伊莎贝尔是刘海+眼罩。

翻遍早期人设八张：约翰、阿尔瓦、所罗门、威廉、霍夫曼、伊莎贝尔**全部**有面部遮挡。
只有珊和丹尼尔例外（一个是小孩，一个是机器人）。

> **一张完全露出、五官端正的脸 = 这个角色不属于这个世界。**
> 遮挡物从这里选：墨镜 / 护目镜 / 厚刘海 / 胡子 / 面巾 / 眼罩 / 绷带 / 头盔 / 异色镜片。

### 1.3c 允许"不合理"

参考图里的东西经不起现实推敲，而这正是设计感的来源：
所罗门的镜片**一红一蓝**（没有理由）、伊莎贝尔的头发**违反重力**、约翰的胡子**不可能长成楔形**。

> 出图时如果每一处都"合理"，那就是没设计。**每个角色至少留一处说不通但好看的地方。**

### 1.3 剪影铁律：**必须有一个歪的东西**

每个角色的剪影里，至少有一个打破对称的突出物：

- 呆毛 / 一撮翘起的头发（约翰、Lee）
- 翘起的衣领（约翰的红马甲领）
- 头部附件（阿尔瓦的头盔球节、Lee 的 3D 眼镜）
- 背后的东西（锅、背包、天线、垂下的电线）
- 极端发型（狮鬃女、伊莎贝尔的长白发）

**没有这个歪点，角色在群像里会消失。**

## 2 · 脸（FACE）

### 2.1 简化到什么程度

- **眼睛** = 纯黑椭圆 / 豆形色块，**无眼白或极少眼白**。有虹膜时是单色块 + 一个白点。
- **鼻子** = 一个色块或干脆省略。
- **嘴** = 一条短线，或笑时的梯形/香蕉形色块。
- **腮红** = 两块扁圆硬边色斑（不是渐变红晕）。
- **眉毛** = 粗、短、独立的色块，不贴着眼睛。
- 五官整体**往脸的下半部集中**，额头留大片空白。

### 2.2 **遮挡是常态**（重要）

参考里 **约一半角色看不到眼睛**：

| 角色 | 遮挡方式 |
|---|---|
| 约翰 | 头发 + 胡子遮住整只眼睛，只露一点 |
| 阿尔瓦 | 头盔 + 眼罩 / 创可贴 |
| 所罗门 | 单边护目镜 |
| Lee | 红蓝 3D 眼镜 |
| 霍夫曼 | 圆框老花镜（镜片反白） |
| 伊莎贝尔 | 厚刘海压到眉毛 |

> 👉 **遮挡不是偷懒，是这套画风的核心设计手段。** 它同时解决三件事：
> ① 增强剪影识别度 ② 免去五官透视的负担 ③ 制造神秘感和"怪"
>
> 我们的世界更有理由用它：**锈汛让护目镜和面巾成为日常穿戴。**

### 2.3 母题：红鼻头

约翰、霍夫曼、紫发老者都有**明显的红鼻头**（`#DD5233` 一带的正圆或球形色块）。
这是这套人设的签名之一，代表"糙、老、喝酒、风吹日晒"。**可以用，但一个群像里别超过 2 个。**

### 2.4 五官夸张法（照片转译时用）

**不还原五官，找出最偏离平均值的 1–2 个五官，夸张 1.5–2 倍，再用上面的简化语言画出来。**

| 照片里的特征 | 夸张后在赛璐璐语言里的样子 |
|---|---|
| 眼睛大 | 巨大的圆形黑色块，占脸宽 1/3 |
| 眼睛小 / 眯 | 两条短横线，或一对小豆点 |
| 眉毛浓 | 两条极粗的独立色块，几乎连成一条 |
| 眉毛细 / 挑 | 两条纤细的弧线，挑得很高，离眼睛很远 |
| 鼻子大 / 鼻头圆 | 球形色块，可以上红鼻头母题 |
| 鼻子小 / 挺 | 一个小色块或直接省略，只留一条短线 |
| 嘴唇厚 | 明确的双色块唇形（这套画风里很少见，所以一旦用就很有辨识度） |
| 嘴唇薄 | 一条极简的短线 |
| 下巴方 | 下颌轮廓做成明显的梯形 |
| 脸圆 | 正圆脸 + 腮红加大 |

**只挑 1–2 个，其余全部回归到默认简化脸。** 挑三个以上会变成漫画丑化，不是风格化。

## 3 · 服装（COSTUME）—— 会讲故事的层

### 3.1 三层结构是标配

```
内层  T恤 / 衬衫 / 高领        ← 露出领口、袖口、下摆一点点
中层  卫衣 / 衬衫 / 背心       ← 主要的色块面积
外层  马甲 / 夹克 / 大衣 / 风衣  ← 最宽的剪影、最强的颜色
配件  腰包 / 背带 / 护目镜 / 手套 / 围巾 / 徽章
```

参考里几乎每个角色都能拆出这三层。**只有一层的角色会显得单薄、不属于这个世界。**

### 3.2 磨损词汇表（拾荒美学）

补丁 · 胶带 · 明缝线 · 别针 · 徽章 · 贴纸 · 卷边 · 破洞露内衬 · 磨白的边角 · 不成对的手套 · 用绳子代替的皮带 · 缠在小臂上的绷带 · 挂在身上的小工具

> **规则：每个角色至少 3 处磨损细节，且必须能说出它们的来历。**
> "这块补丁是去年汛期被铁皮划的" —— 说得出来的细节才有说服力。

### 3.2b 细节密度预算 ⚠️ 质感差距的最大来源

数一遍参考图身上**可数的独立小细节**：

| 角色 | 可数细节 | 都有什么 |
|---|---|---|
| 约翰 `06` | **约 20** | 6+ 圆徽章/别针、4 条胶带、3 块补丁、破洞垂布条、字母 `J`、翻领、污渍块、手套破口、鞋带、拉链 |
| 阿尔瓦 `08` | **约 16** | 数字 `1`、4 块补丁、3 个圆徽、头盔 4 个球节、双色手套、条纹、闪光符号、领巾 |
| 威廉 `12` | **约 18** | 提灯、烟、皮带扣、毛领、3 块补丁、胶带、破鞋、袖口卷边、挂绳、口袋 |

**我们第一轮出图只有 4–5 个。差了一个数量级——这就是"看着不像"的主因。**

### 硬预算（每个角色）

**按角色类型分档**（八张官方实测跨度 5–20，不是所有角色都堆满）：

| 角色类型 | 合计细节 | 例 |
|---|---|---|
| 成人拾荒者 / 工匠 / 走商 | **15–20** | 约翰 20、威廉 18、所罗门 15 |
| 少年 / 改造者 | **10–15** | 阿尔瓦 14、伊莎贝尔 10 |
| 儿童 / 机械 / 上环出身 | **5–8** | **珊只有 5** |

> ⚠️ 早期版本对所有角色一律要求 ≥15，那是从约翰/阿尔瓦/威廉三张过度泛化的。
> **珊身上只有 5 个细节，她照样成立**——干净本身可以是角色特征（上环出身尤其如此）。

### 细节的**种类**要按职业分配方，不能都是同一套

实测问题：连出多版，每个角色的补丁/挂件/徽章**数量一样、种类也一样**，像同一个模板刷出来的。
参考图不是这样——约翰身上是**圆徽章和胶带**，威廉身上是**提灯和皮带扣**，阿尔瓦身上是**号码和方补丁**。

| 职业 / 出身 | 细节配方（各占大头的类型） | 明显不该有的 |
|---|---|---|
| **接线人** | 线缆卷、插头、绝缘胶带、小工具、接口盖 | 大量徽章 |
| **炉工** | 护目镜、面巾、煤灰污渍块、耐热贴片、扣具 | 精致挂件 |
| **拾荒者** | 杂色补丁、绳结、捡来的小物件、不成对的东西 | 制式徽章 |
| **走商** | 挂包、绳、票据/单子、铃铛、地图筒 | 工业零件 |
| **汛官** | 制式徽章、袖标、哨子、编号牌（**整齐**，和别人相反） | 破洞、杂补丁 |
| **上环出身** | 几乎没有。**干净就是他的特征** | 补丁、磨损 |

### 细节梯度（做多个角色时）

参考图的细节量跨度是 **4 倍**（珊 5 → 约翰 20）。

> **同一批角色里，细节最多的应是最少的 ≥3 倍。**
> 如果每个人都是 15 个，那不是设计，是刷模板。

### 分布也要不匀

参考图的细节是**成簇**的：约翰全在马甲胸口，袖子和裤子几乎空白。
不要让细节均匀铺满全身——`measure.py` 的**负空间**指标（20–36%）就是在测这个。

### 细节词汇表（凑数用，但每个都要说得出来历）

圆形徽章 · 别针 · 圆形贴纸 · 胶带条 · 方补丁 · 异形补丁 · 明缝线 · 破洞 · 垂下的布条 ·
拉链 · 卡扣 · 口袋（不同大小） · 挂绳 · 小工具 · 污渍色块 · 字母 · 数字 · 卷边袖口 ·
不成对的手套 · 用绳子代的皮带 · 缠在小臂的绷带 · 领口翻出的内衬

> 💡 **细节要"杂"，不要"整齐"。** 参考图里的徽章大小不一、颜色互相不搭、位置随机。
> 一排整齐的同款徽章 = 制服感 = 错。

### 3.2b-2 阴影占比（硬性指标）⚠️「阴影运用差太多」的量化

实测八张官方早期人设：**暗部占人物面积 33.6%–76.7%，中位 43.7%**。
我们的出图只有 **26–30%**——不到参考的一半，所以整张图发平、没有体量。

| | 官方参考 | 我们出图 |
|---|---|---|
| 暗部占比 | 33–77%（中位 44%） | 26–30% ❌ |
| 相对线宽 | 5.4–6.6 | 3.4 ❌（细了一半） |

**阴影不是点缀，是主要造型手段。** 参考图里往往**整条手臂、整个下半身、整片衣摆**是一整块暗部。

写进提示词的说法：
```
Large shadow shapes cover about half the figure — a whole sleeve, the lower half of the coat,
the underside of the boots are each one solid darker shape.
```

跑 `python3 checklists/check.py 出图.png` 会直接量出这两项。

### 3.2c 线宽变化与剪影不规则

参考图和我们出图的另外两个显性差距：

| | 参考图 | 我们第一轮 |
|---|---|---|
| 线 | **像毛笔**：剪影处极粗，内部细且常断开 | 均匀等宽，像矢量描边 |
| 下摆 | **撕裂状锯齿**，垂布条 | 平整直边 |
| 领子 | **外翻炸开**，尖角 | 服帖 |
| 头发 | **大而尖的锐角发束** | 圆润碎发 |
| 外套廓形 | **喇叭状外扩过胯** | 贴身 |

这五条都要显式写进提示词，模型不会自己从参考图学到。

### 3.3 印刷元素（签名）

每个角色**至少一个**：号码（阿尔瓦的 `1`）、字母（丹尼尔的 `S`）、几何徽章、贴纸、旧世 logo 残片。
在我们的世界里，这些通常是**旧世遗物**——一件印着看不懂的旧世字样的 T 恤，是这个世界的时尚。

### 3.4 服装 = 世界观的输出端

按 `world/00-core.md` §8 四问，服装自动生成：

| 世界观答案 | 服装表现 |
|---|---|
| 出身**桥城** | 杂色、市井、混搭、颜色鲜艳、有点脏 |
| 出身**釜谷** | 工装、帆布、护目镜、面巾、煤灰色、真的实用 |
| 出身**岸线** | 油布外套、防水、最多补丁、颜色最沉、背最多东西 |
| 出身**上环** | 整洁、剪裁好、颜色少、白/藏青、**几乎没有磨损**（这就是他的特征） |
| 职业**接线人** | 围裙、工具卷、手上有油、身上挂零件 |
| 职业**汛官** | 制服 + 袖标 + 哨子 + 徽章，但制服也旧 |
| **有义肢** | 露出接口、缠胶布、外接电池包、走线沿手臂爬 |

## 4 · 配色分配法（角色级）

每个角色的配色 = **1 + 2 + 1**：

| 槽位 | 占比 | 内容 |
|---|---|---|
| **主强调色** ×1 | 20–30% | 高饱和，通常在外层。红/橙最常见 |
| **中性色** ×2 | 50–60% | 低饱和褐/卡其/灰绿/骨白，做底 |
| **意外色** ×1 | 5–10% | 一小块出人意料的颜色（紫、青、粉），通常在头发或小配件 |

看 `27-opening-cast-lineup.png`：红马甲、橙风衣、粉头发、蓝莫西干——**每个角色一个记忆点色**，其余全是中性色托底。

### 照片的主要衣物是深色 / 无彩色时怎么办

常见冲突：规则说「主强调色穿在面积最大的外层」，但照片里那件大衣是黑的或藏青的。
**不要为了上色改掉照片的衣服**——那件深色大衣是识别锚点。

解法是风来之国自己的母题（见 `18-opening-character-designs.png` 里那个黑大衣角色）：

> **深色大衣 + 翻出来的高饱和内衬 / 大翻领。**
> 大衣是中性主体，翻开的内衬承担 20–30% 的强调色。

同样可用的变体：深色外套 + 鲜艳内搭、深色外套 + 亮色围巾、深色外套 + 亮色靴子。
**强调色的面积要够，但不必是最外那一层。**

> ⚠️ **错误做法**：给角色五个高饱和色。会立刻变成通用手游立绘。
> 中性色的大面积存在，才是这套画风高级感的来源。

完整色卡见 `palette.md`。

## 5 · 角色原型库（照片落位时选一个起手）

| 原型 | 形体特征 | 典型元素 |
|---|---|---|
| **糙汉守护者**（约翰型） | 宽厚、上重下轻到极端、头发和胡子遮眼 | 红马甲、平底锅、大手套、红鼻头 |

| **痞气青年**（Lee 型） | 瘦、站姿歪 | 夸张发型、怪眼镜、letterman 外套、耳环 |
| **落魄智者**（威廉型） | 佝偻、长外套 | 提灯、烟、破皮鞋、乱发 |

## 6 · 群像规则（做多个角色时）

- **怪度配额**：每 4 个"正常"角色，配 1 个明显跳脱的（机器人 / 狮鬃 / 极端造型）。
- **高度差**：一排角色的身高必须有明显阶梯，别都一样高（看 27 号图：从 1:3 的机器人到 1:5.5 的成人）。
- **色彩不撞**：主强调色在群像里不重复。
- **年龄混杂**：老人、成人、少年、小孩、非人——风来之国的群像永远是混龄的。

## 女性角色 ⚠️ 曾经整组都出不来

实测：四张真人照片里两张是女性，出图**全部是中性偏男**。三个原因，全在 skill 自己身上：

| # | 原因 | 修法 |
|---|---|---|
| 1 | **模板里写死了 `he` / `his` 三处** | 全部改成 `the figure` / 中性表述 |
| 2 | **上墨锚固定用 06-john（男性）** ——等于每次都给模型一个男性范本 | **按性别/年龄换上墨锚**，女性用 `09-isabel` |
| 3 | 没有性别槽位，性别信息只藏在 `PHOTO:` 段末尾 | 加 `WHO: a {性别与年龄}` 段，放在最前面的身份位 |

## 五官必须逐人不同 ⚠️ 曾经所有角色一双眼

模板里 `two simple dark eye shapes` 是**写死的**，而且排在夸张槽位**之后**，直接覆盖掉。
结果六个角色一双眼，"体现不出人物形象上的差别"。

而官图的眼睛差别极大：

| 角色 | 眼睛 |
|---|---|
| 约翰 | 完全被胡子和墨镜吞掉 |
| 阿尔瓦 | 一只大而圆的青色，另一只被绷带遮住 |
| 所罗门 | 红蓝异色镜片 |
| 伊莎贝尔 | 重眼睑、细长 |
| 霍夫曼 | 圆眼镜后凸出 |
| 珊 | 大圆黑眼 |
| 威廉 | 下垂三白眼 |

### 修法：FACE 拆成四个独立槽位

```
FACE:      发色（明确写出）+ 发型的形 + 遮挡
EYES:      眼睛画法（从照片读眼型后放大）+ 眉毛画法
SIGNATURE: 一个来自照片的最突出特征，放大约两倍
其余      : 短嘴线 + 两块硬边腮红，别的都没有
```

**`SIGNATURE` 是"像不像本人"的唯一承重点。** 不要求五官都还原，
但**必须有一处来自照片、并且夸张到两倍**。

实测四张真人照片：眯眼笑 / 大杏眼配浓直眉 / 小眼被重眉压 / 笑成月牙——四张脸终于各不相同。

## 体型可以变，压缩不能变

**拆成两件事**：

```
BUILD: big head, five heads tall, and short — the whole figure stays compressed.   ← 常量
       Within that compression the mass is {体块}.                                  ← 照片变量
```

`{体块}` 只填**厚薄**，四选一：
`a round barrel of a torso` / `a square heavy slab of a torso` /
`a narrow light torso with sloping shoulders` / `a wiry compact torso`

> ⚠️ **「高 / 瘦长 / 修长」这类词一律不填。**
> 实测：`slim` 单独出现会和 `short` 打架，模型把人拉长，头身比从 5 退到 7。
> 而 `a narrow light torso` 只说厚薄不说长度，**纤细出来了，压缩也保住了**。

四张真人照片验证：厚方块 / 纤细 / 精瘦 / 圆桶四种体块都成立，**头身比全部保持 5 左右**。

## 杂物不能都是徽章 ⚠️

模板的 `DETAIL` 段一度把徽章清单写死，结果十个角色胸口全是一簇圆徽章，同质化。

**官图的杂物类型差别极大**：

| 角色 | 身上挂的是什么 |
|---|---|
| 威廉 | **提灯 · 烟 · 皮带扣 · 毛领** |
| 霍夫曼 | **一大串钥匙 · 圆眼镜 · 胸前小瓶** |
| 伊莎贝尔 | **吉他 · 眼罩 · 创可贴** |
| 丹尼尔 | **掉下来的螺丝 · 字母 S** |
| 珊 | 几乎没有 |
| 约翰 | 圆徽章 · 胶带 · 补丁（**这才是徽章型**） |

### 六类杂物，每个角色主用一到两类

| 类 | 例 | 适合 |
|---|---|---|
| **挂件类** | 钥匙、铃铛、小工具、绳上挂饰 | 教书人、走商、市井长辈 |
| **布类** | 补丁、胶带条、明缝线、垂布条 | 拾荒者、炉工 |
| **器物类** | 提灯、乐器、锅、一捆书 | 乐手、面摊主、教书人 |
| **线材类** | 电线、绳、链、盘起的缆 | 接线人、机械师 |
| **徽章类** | 圆徽、别针、贴纸 | 汛官、有组织身份的人 |
| **纸类** | 票据、单子、盖章条、纸卷 | 走商、广播员、汛官 |

> **两个角色不该主用同一类。** 一组人里徽章型最多两个——
> 徽章意味着「有组织身份」，拾荒者和乐手身上挂一堆徽章是不合理的。

## 表情表：一张图六格，不是六张图

动画业界的 expression sheet 就是**一张 model sheet 上排 6–12 个表情**——
最少 6（平静/开心/难过/生气/惊讶/害怕），8–10 更好，生产级 12+，
常配 front / profile / three-quarter 三视角。

**为什么必须是一张图**：同一次生成，发型、镜片、领口、颜色天然一致。
分六次出必然漂移——这和编辑链累积漂移是同一个问题。

### 一致性靠模板里这一段

```
SAME PERSON EVERY TIME: in all six cells the hair is identical in colour, length and shape
— {发色发型}; {刘海或遮挡} stays exactly as it is; the collar and shoulders show
{领口与肩部} in the same colours; {招牌特征} appears in every cell.
Only the eyes, brows and mouth change from cell to cell.
```

**把不变的东西逐项点名，并明确只允许眼眉嘴变。** 实测两个角色（长直发+浓眉、方框眼镜+络腮胡）
六格全部保持一致，包括眼镜形状、胡子轮廓、条纹领这些细节最多的部分。

### 扩到 12 个

网格改四列三行，情绪加：害怕 / 得意 / 厌恶 / 疲惫 / 害羞 / 大哭。
