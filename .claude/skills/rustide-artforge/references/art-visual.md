# 画风拆解 A ·【美术视觉】

> 角度：**这张图是怎么被画出来的**。线、色、面、光、质感、画布。
> 数据来源：`assets/refs-cel/` 16 张官方图的直接观察 + ImageMagick 实采色值。
> 设计层面（剪影、比例、人设语言）在 `art-design-direction.md`。

---

## 0 · 一句话锚点

**粗的暖色描边 + 硬边平涂色块 + 一层阴影 + 没有笔触。**
不是厚涂，不是渐变，不是水彩，不是像素。是**动画赛璐璐设定稿**。

---

## 1 · 线（LINE）—— 最容易做错的一层

### 1.1 铁律：**没有纯黑描边**

实采数据，8 张参考图里最深的色：

| 图 | 最深色 | 是什么 |
|---|---|---|
| 06 约翰 | `#2E241F` | 暖深褐 |
| 08 阿尔瓦 | `#2B2621` | 暖深褐 |
| 09 伊莎贝尔 | `#24211C` | 暖深褐 |
| 10 所罗门 | `#211C17` | 暖深褐 |
| 12 威廉 | `#44322D` | 红褐 |
| 13 霍夫曼 | `#403C37` | 灰褐 |
| 28 Lee | `#271D27` | 冷深褐（唯一偏冷） |

**一次 `#000000` 都没有。** 出图 prompt 里必须显式写 `warm dark brown outline #2E241F, never pure black`，否则模型默认给你黑边，整张图立刻变成通用日漫。

### 1.2 线色随材质走（色相内的深色）

同一张图里，描边不是一个颜色：

- **皮肤** → 红褐线（`#8C5A3C` 一带）
- **布料 / 外套** → 深褐线（`#3A2E26` 一带）
- **金属 / 机械** → 深蓝灰线（`#3A4450` 一带）
- **头发** → 比发色更深 2–3 档的同色相

这叫 **色线 / colored line art**。它是这套画风"手绘温度"的来源。

### 1.2b 线是**曲**的，不是直的 ⚠️ 「太精致」的量化形态

实测轮廓曲率（数值越高＝方向变化越频繁＝越手绘）：

| | 曲率 |
|---|---|
| 官方参考 06/09/12/13 | **1.09 – 2.22** |
| 我们的出图 v12/v17/v24 | **0.81 – 0.85** ❌ 全部低于参考下限 |

参考图里**没有一段真正的直线**：胳膊是外凸的弧、衣摆是波浪、下巴是圆的、裤管两侧不平行。
生图模型默认会画干净的直边——那是矢量感，不是手绘感。

写进提示词的说法：
```
Every edge is a slightly uneven curve — arms bow outward, hems wave, trouser sides are not
parallel, the jaw is round. The contour keeps changing direction.
```

### 1.2c 「偏油」的量化形态 ⚠️ 与官方最大的质感差距

统一缩到 700px 高后实测：

| | 平涂率（与右邻完全同色） | 色密度（色/万px） |
|---|---|---|
| 官方 06/09/12/13 | **15.4 – 25.0%** | 1188 – 2483 |
| 我们的出图 | **2.2 – 6.4%** ❌ | 2010 – 3528 |

**官方图有大片真正的平色块；AI 出图几乎每个像素都和邻居差一点点。**
这种连续微变就是肉眼看到的"油"——它不是颜色问题，是**填色方式**问题。

### 三条对策（措辞层，不是重抽）

1. **`cel-shaded` 这个词有陷阱。** 它在 CG 语境里指**三维卡通渲染**（toon shader），
   会把图往光滑渲染感带。改用 **`cel-painted on acetate`** / **`flat colour fields`**。
2. **明确限定色数**：`the whole figure uses about twenty flat colour fields`。
3. **强调"整块同色"**：`each area is one single colour, identical across the whole area`
   —— 比 `flat` 一个词有力得多。

`checklists/check.py` 出图后会直接量这两项。

### 1.3 线宽

- **粗、闭合、相对均匀**，但有轻微起伏和呼吸——不是矢量等宽线，也不是细日漫线。
- 相对画布：全身立绘高度 500px 时，主轮廓线约 **3–4px**，内部结构线约 **2px**。
- **外轮廓 > 内部结构线**：剪影边缘的线明显更粗，这是让远看剪影成立的关键。
- 端点略尖（笔压收尾），转角保留一点点手抖。

### 1.4 两套线，别混

| | 早期人设立绘（06–13） | 开场动画设定表（18/24–29） |
|---|---|---|
| 线质 | **更土、更抖、更粗**，笔触感明显 | **更稳、更细、更工业**，接近成品动画线 |
| 闭合度 | 完全闭合 | 允许开口线、线不封边 |
| 用途 | 游戏人设 / 主视觉 | 动画设定 / 分镜 |
| **本 skill 默认** | ✅ **默认用这套** | 需要"动画感"时切换 |

`29-opening-john-cables-cel.png` 是特例：**蓝紫色的粗糙铅笔线残留在色块边缘**，色块甚至溢出线外。这是"保留 rough 线的赛璐璐"，很好看，但**不作为默认**——太难稳定复现。

## 2 · 色（COLOR）

### 2.1 平涂 + 硬边阴影，最多两层

每个色块的完整构成：
```
基础色  →  阴影色（硬边，同色相压暗 + 略降饱和）  →  [可选] 高光（一小块，非必须）
```

- **绝对不要渐变**。不要 airbrush，不要柔边，不要 ambient occlusion 涂抹。
- 阴影是**一块颜色切进另一块颜色**，边界是硬的、是有形状的。
- 阴影形状本身要**概括**——一整条手臂一块阴影，不要按解剖分五块。
- 一个色块**最多一层阴影**。想要更多层次？换成不同的色块，别叠影。

### 2.2 阴影色怎么算

不要用"降明度"。用 **同色相 + 降明度 15–25% + 降饱和 5–10% + 微微偏冷或偏紫**。

| 基础色 | ❌ 错的阴影（纯压暗） | ✅ 对的阴影 |
|---|---|---|
| 砖红 `#DD5233` | `#A03D26` | `#B24A38`（偏紫红） |
| 骨白 `#F1DEA9` | `#B5A67E` | `#C9B58C`（偏暖灰） |
| 军绿 `#5E6B4B` | `#454D36` | `#48533F`（偏蓝绿） |

### 2.3 纸感 / 噪点

- 早期立绘：**极轻微的纸纹**，几乎看不见。
- 开场设定表：**完全干净**，扫描白底。
- **不要**做旧、不要重颗粒、不要网点、不要丝网印刷质感——那是这个 IP 的**另一套**海报画风（厚涂系），混训会毁掉赛璐璐的干净感。

## 3 · 光（LIGHT）

- **单一光源，从上方偏一侧**（通常左上或右上 45°）。
- 光**不塑造体积**，只做"这一面亮、那一面暗"的二值切分。
- 没有反射光、没有环境光、没有次表面散射、没有发光边缘。
- **脚下没有投影**，或只有一条极淡的水平地平线（见 `27-opening-cast-lineup.png`）。
- 人设表 = 无环境光照。**光是画上去的，不是算出来的。**

## 4 · 材质（MATERIAL）—— 用色块，不用笔触

这是"拾荒感"的落地方式。所有磨损都靠**形状**表达，不靠**笔触**表达。

| 要表达 | ✅ 做法 | ❌ 别做 |
|---|---|---|
| 污渍 | 一块边缘不规则的深色平色块 | 喷枪脏化 / 噪点叠加 |
| 补丁 | 一个矩形/异形色块 + 一圈缝线短划 | 布纹贴图 |
| 破洞 | 挖空 + 露出内层色 + 几根垂线 | 撕裂笔触 |
| 胶带 | 灰白半透感的矩形色块（实为不透明浅灰） | 高光反射 |
| 金属 | 灰蓝平色 + **一条硬边高光** | 金属渐变 |
| 皮革 | 中褐平色 + 一块暗部 + 边缘缝线点 | 光泽渐变 |
| 毛领 / 绒 | 锯齿状边缘的浅色块 | 毛发笔刷 |

**印刷元素**是这套画风的签名：号码、字母、徽章、贴纸、logo。
参考里 阿尔瓦的 `1`、丹尼尔的 `S`、Lee 的 `X` 补丁。
👉 **每个角色至少一个印刷元素**，且印刷元素要跟着布料的褶皱一起变形。

## 5 · 画布与呈现（CANVAS）

| 项 | 规格 |
|---|---|
| 底色 | **纯白**（`#FFFFFF`）或**透明**。参考里 16 张全是。 |
| 背景元素 | **零**。没有场景、没有装饰框、没有渐变底、没有光晕。 |
| 构图 | 单人全身居中，四周留白 8–12% |
| 视角 | **平视正面 或 正面微侧（约 15°）**。不用仰角、不用俯角、不用大透视 |
| 姿势 | 立绘=站姿放松（T-pose 与 A-pose 之间），重心微偏，手臂自然垂或插兜 |
| 比例参考 | 全身立绘原始素材约 **300×520 – 460×600 px**（低分辨率是原作特性，出图可放大到 1024×1536） |
| 阴影 | 脚下无投影，或一条 1px 地平线 |

## 6 · 两种渲染档位（供 prompt 切换）

| 档位 | 何时用 | 线 | 色 | 参考图 |
|---|---|---|---|---|
| **A · 人设档**（默认） | 角色档案、立绘、图鉴 | 粗、闭合、色线、手绘抖动 | 平涂 + 1 层硬影 + 细节堆料 | `06–13` |
| **B · 动画档** | 开场动画、分镜、群像、动态 | 细、稳、可开口 | 更平、更少细节、更强剪影 | `18 / 24 / 27 / 28` |

同一个角色可以同时出 A 档和 B 档，**档案里的配色和剪影必须一致**。

## 7 · 视觉自检（出图后逐条对）

- [ ] 放大看描边——是暖深褐，不是纯黑？
- [ ] 有没有任何一处渐变？有就不合格。
- [ ] 阴影边界是硬的吗？是**一块**而不是**五块**吗？
- [ ] 背景是纯白/透明、无任何元素吗？
- [ ] 缩到 10% 看剪影——还认得出是谁吗？
- [ ] 有没有笔触质感、颗粒、网点混进来？
- [ ] 身上有没有至少一个印刷元素（号码/字母/徽章/贴纸）？
- [ ] 金属高光是**硬边一条**，不是渐变吗？

## 1.2d 实测：画风差距的根因是**设计**，不是渲染

用 gpt-image-2 对着官图做了一轮闭环实验（评分器七项全部按官图标定），结论：

### 差距排序（目视对比官图 06-john / 10-solomon）

| # | 官图 | 生图默认 | 修法（已写进模板） |
|---|---|---|---|
| 1 | **每件衣服是一整块颜色** | 每件被切成十几块小色块 | `BIG FIELDS: each garment reads as one large unbroken field of a single colour` |
| 2 | **腿是两根光溜溜的细管** | 腿粗短、绑腿补丁堆满 | `The legs are two thin plain dark tubes, bare of any detail` |
| 3 | 细节只占**胸口一小簇** | 满身铺满 | `about five details in one chest cluster; sleeves, back, legs stay clean` |
| 4 | 脸是**纯色块 + 四笔** | 写实皱纹、露牙、脸颊阴影 | `The face is a plain flat shape: two dark eye shapes, a mouth line, two blush patches` |
| 5 | 外轮廓线明显比内部粗 | 内外一样细 | `outer silhouette line heavy and wandering; lines inside thin and sparse` |

**这一组改动把平涂率从 3.4% 拉到 14.8%（官图 15.4–30.9），色密度从 3490 降到 1680（官图区间内）。**
说明"发油/太精细"**不是渲染问题，是设计上没有大色块**。

### ⚠️ 采样方差极大，不要用单张图做判断

同一份提示词跑四次，离官图总距离分别是 **0.87 / 1.64 / 1.05 / 2.89**，平涂率 14.8 / 3.8 / 8.4 / 13.6。
**波动比任何一次"改进"都大。** gpt-image-2 没有 seed。

> **判断一处改动是否有效，至少要 3 张取中位数，并且以目视对比官图为准。**
> 出图后量化（`-colors 28`）也试过，不是确定性改善（五个样本里两个变好三个变差），已放弃。

### 闭环实验最终结论（22 张，对官图目视验收）

**画风稳定下来的五条改动**（全部已写进 `templates/GOLD-from-scratch.txt`）：

| # | 改动 | 官图依据 |
|---|---|---|
| 1 | **每件衣服是一整块颜色** `each garment reads as one large unbroken field of a single colour` | 约翰的红马甲是一整块红 |
| 2 | **腿是两根光溜溜的细管** `two thin plain dark tubes, bare of any detail` | 官图的腿几乎没有细节 |
| 3 | **细节约十个，全挤在胸口一簇**，其余部位留空 | 约翰的徽章全在马甲胸口 |
| 4 | **所有下摆撕成锯齿、领子炸开尖角、垂布条、发梢尖角** `Nothing has a clean straight edge` | 官图没有一条干净直边 |
| 5 | **主强调色是高饱和红橙，且穿在面积最大的那件上** | 约翰的红马甲 = 记忆点 |

> ⚠️ 第 3 条曾矫枉过正到"五个细节"，结果太干净、不像官图。**十个成簇**才对。
> ⚠️ 第 5 条不做，饱和度上不去——因为中性色占了最大面积。

**验收方式：目视对比官图，不看单项参数。** 参数只用来确认没有大幅倒退。

**泛化验证**：同一模板换成完全不同的角色（釜谷接线人 → 桥城面摊主，服装/道具/配色无一相同），
画风、比例、脸、线、平涂全部保持。**这是"美术风格固定"的判据。**

### 材质状态词会让平涂率腰斩

实测：澡堂主的杂物描述里只有一个 `damp at the edges`，
去掉这一个词，**平涂率 3.2% → 6.6%**，直接进区间。其余一字未改。

已做进 `check.py` 门禁的材质词：
`damp · wet · soggy · greasy · oily · sooty · scorched · singed · grimy ·
weathered · stained · crusted · flaking · mildewed · sweaty · smeared · caked`

> **磨损要用「形状」表达**——补丁、破洞、缝线、垂布条、锯齿下摆。
> **不要用「表面状态」表达**——那是在点材质渲染。
