# 校验清单 · 出图后逐条对

**先跑测量，再勾选。**

```bash
python3 checklists/measure.py <出图.png>
```

它会量出上重下轻、负空间、描边色，并生成一张 `*-ruler.png` 标尺图判头身比。
阈值来自 `--calibrate` 在八张官方早期人设上的实测区间，**不是拍脑袋定的**。

> ⚠️ **头身比不要用眼估、更不要直接打勾。**
> 实测教训：某一版 QC 报告自评「约五至五点五头身 ✅」，标尺图量出来是 **7.8 头身**。
> 长大衣会让人整体读作瘦高，眼睛会骗人。**看标尺图：下巴必须落在第一条红线上或略高。**

三组，任何一条不过就回去改。**不要放行"差不多"的图**——风格是靠拒绝维持的。

## A · 美术视觉（依据 `references/art-visual.md`）

- [ ] 放大看描边 —— 是**暖深褐**（`#2E241F` 一带），不是纯黑？
- [ ] 描边有随材质变色吗（皮肤红褐 / 金属蓝灰）？
- [ ] 外轮廓线比内部结构线明显更粗？
- [ ] **零渐变** —— 全图找不出一处渐变、喷枪、柔边？
- [ ] 阴影边界是**硬**的，且每个色块**只有一层**？
- [ ] 阴影形状是概括的**一块**，不是按解剖分的五块？
- [ ] 背景纯白 / 透明，**无任何元素**、无渐变底、无光晕？
- [ ] 脚下无投影（或只有一条细地平线）？
- [ ] 没有颗粒、纹理、网点、丝网、笔触混进来？
- [ ] 金属高光是**硬边一小块**，不是渐变？

## B · 设计方向（依据 `references/art-design-direction.md`）

- [ ] 头身比在 **1:4.5 – 5.5** 之间（儿童 1:3.5–4）？→ **看 `*-ruler.png`，不要用眼估**
- [ ] **上重下轻** —— 外套最宽、腿明显细、靴子大而方？
- [ ] 手是**连指块**，没画手指分节？
- [ ] 剪影里有那个**歪的东西**？
- [ ] **缩到 32px** 看，还认得出是谁？
- [ ] 服装是**三层**（内 / 中 / 外）+ 配件？
- [ ] 至少 **3 处磨损**，且每处说得出来历？
- [ ] 至少 **1 个印刷元素**（号码 / 字母 / 徽章 / 旧世 logo）？
- [ ] 配色是 **1 主 + 2 中性 + 1 意外**，中性色占 50% 以上？
- [ ] 脸够简化 —— 纯黑椭圆眼、小嘴、硬边腮红、粗短眉？
- [ ] 夸张的五官**只有 1–2 个**，不是三个以上（那是丑化）？

## C · 世界观（依据 `references/world-rustide.md`）

- [ ] **四问**全部答得上来？
- [ ] 服装能从"锈汛怎么对待他"推出来？
- [ ] 技术水位没超标 —— 无手机 / 触屏 / 全息 / 霓虹 / LED / 能量武器 / 无人机？
- [ ] 如果有赛博层 —— 是**手工的、会漏油的、穷的**，不是光滑高科技？
- [ ] 情绪对吗 —— **邋遢但不悲惨，破但不荒**？
- [ ] 出身地的视觉倾向对得上（桥城杂 / 釜谷工装 / 岸线油布 / 上环整洁）？
