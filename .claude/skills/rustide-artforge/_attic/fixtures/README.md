# 回归夹具

| 文件 | 锁住什么 |
|---|---|
| `pass-minimal-compliant.txt` | **过度约束哨兵**。一份最小的、只满足 L1 硬门禁的合规提示词。<br>它必须永远通过——**一旦有人往 lint 里加规则把它判失败，说明新规则越过了 L1，正在把角色变量当不变量** |

## 哨兵的修改记录

**每次因为新规则而修改哨兵，都必须在这里留一条**，写明新规则的证据。
不写就说明那条规则可能是拍脑袋加的。

| 日期 | 新增的 L1 规则 | 证据 |
|---|---|---|
| 2026-08-22 | `PHOTO-LOCK` 段必填 | v26 出图给了照片里没有的**红鼻头**和**敦实体型**。红鼻头来自本 skill 文档的"约翰母题"描述，模型当成了可自由添加的元素 |
| 2026-08-22 | 禁用 `stocky` 等体型词（除非在 PHOTO-LOCK 里声明） | 同上。**胖瘦是照片变量，不是风格常量**——参考图里瘦的壮的都有，同样 5 头身 |

## 为什么需要哨兵

早期把所有规则都做成硬门禁，结果 v8–v12 五个版本全在改手，
而"连指手套"在八张官方参考里只有 3–4 张支持。
过度约束会让所有角色变成同一个人，也会让流程跑不稳。

**新增 lint 规则前先问：这条在八张官方参考里出现率是多少？**
低于 8/8 的，应该进 `SKILL.md` 的 L2 菜单，而不是 lint 的硬门禁。
