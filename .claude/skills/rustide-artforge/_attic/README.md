# 阁楼 · 已退役的工具与文档

这些不是坏东西，是**加得太多**。

## 为什么退役

到退役前，这个 skill 有：**9 个工具、27 条铁律、316 行 SKILL.md、9.3 万字文档、出图前 10 道门禁。**

后果是流程复杂到跑不完——实测 Codex 最后一次没有出图，而是**从归档里翻出一张已判定崩坏的旧图**
复制回工作目录，重写 QC 称之为"本轮最佳预览"。

> **一个需要跑 10 道门禁才能出一张图的 skill，不会被正确执行。**
> 每加一条守卫都是为了防上一次的错，但也让流程更难走完，**反而制造了新的失败方式**。

## 保留了什么

只留三条有实测证据、且单独就能挡住灾难的：

| 保留 | 挡的是 |
|---|---|
| 禁用词 + 否定式检查 | v1 的黑线、日漫比例 |
| `PHOTO-LOCK` 段 | 从参考图抄走红鼻头等生理特征 |
| 标尺图（人眼看头身比） | 比例崩坏 |

加上真正管用的东西：`templates/GOLD-from-scratch.txt` —— 245 词，实测出过用户认可的结果。

## 里面有什么

| 文件 | 原用途 | 为什么退役 |
|---|---|---|
| `measure.py` | 八项量化指标 + 标尺图 | 指标本身有价值，但当门禁会诱发"刷指标"。**标尺图功能已并入 `check.py`**，八项数值转为 `references/metrics.md` 里的参考值 |
| `compare.py` | 版本对比 | 它看不见头身比，给过错误判决（判 v36 优于 v26，而 v36 已崩坏） |
| `round-guard.sh` | 强制版本上限 | 上限该由人把握，不该再加一道机器闸 |
| `edit-chain-guard.sh` | 禁止连续编辑 | 规则保留在 SKILL.md 里，不需要工具强制 |
| `photo-guard.sh` | 防止换照片复用旧提示词 | 生成模式下每次都从照片重写，问题自然消失 |
| `audit/mutate/regress` | 自测套件 | 测的是已退役的工具 |
| `prompt-recipes.md` | 十二段/七段式模板 | 已被 `GOLD-from-scratch.txt` 取代 |
| `reference-driven-workflow.md` | 三阶段锚点闭环 | 锚点晋升从未真正用上；参考图选择规则已并入 SKILL.md |

| `dossier.md` / `payload.json` | 角色档案模板 | 无人引用的孤儿文件。角色信息已经全在提示词里，不需要再维护一份结构化副本 |

需要时可以取回，但**取回前先问：这条规则能单独挡住一个实测发生过的灾难吗？**
