# 风来之国 · 赛璐璐动漫 · 角色立绘

这包只收**平涂赛璐璐 / 普通动漫立绘**这一路，不收手绘厚涂海报，也不收像素实机。

## 里面有什么

- 早期 / BETA 全身立绘：约翰、珊、阿尔瓦、伊莎贝尔、所罗门、丹尼尔、威廉、霍夫曼
- 约翰+珊行走立牌
- 开场动画造型表（Souviens Ten-Zan / Arnaud Tribout）：原一张 + 本轮补的姿势表、护目镜角色表、约翰珊动作表、全员排队、Lee 三视图、约翰缆绳赛璐璐帧

喂 AI 时优先看：早期全身立绘一整排 + 开场造型表 / 全员排队。人设语言在这边最完整。

## 画风重点（复刻时盯这些）

1. **线**：粗、闭合、相对均匀。比厚涂海报干净，但仍是手绘感粗线，不是细动漫线。
2. **色**：块面平涂，几乎没有纸纹和点刻。阴影是硬边赛璐璐，一块颜色切另一块。
3. **体积**：大头、粗躯干、细腿、大靴。剪影优先，不追求写实结构。
4. **脸**：简化。约翰胡子遮眼+红鼻；珊圆黑眼+小嘴；腮红是简单色块。
5. **衣服**：拾荒感还在（补丁、胶带、别针），但用平色表示磨损，不用笔触堆出来。
6. **呈现**：黑底或白底全身立牌 / 造型表，像贴纸或动画设定，不是场景海报。

开场造型表比早期立绘更「动画工业」：线更稳、色更平。早期立绘更土、更怪、更接近游戏人设。

不要和「手绘厚涂海报」混训。这边要的是平涂块面，不是颗粒和丝网。

官方公开的赛璐璐角色图就这些。Wiki Supporting Art 没有更多 Early Art；官网立牌是 3D 或厚涂；Design Works 没有可下载的角色模型页。
