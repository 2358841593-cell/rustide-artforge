## 覆盖缺口与视觉语法（中文）

**覆盖：** 白天市井（新坝地下铁、九龙门鱼市、SLUM 拱门摊贩）、地下夜（波特岛拖车营、HELLO GROCERY）、黄昏（庭院菜园、銭屋街景）、荒野（列车、鲸鱼营地、废墟塔屋）、密林战斗两套敌人、工业/科技/洞穴地牢、摄影棚电影光、车厢住宅、烹饪与聚餐、所罗门问答秀。Xbox 补齐了 Steam 被压成 720p 的夜景。Octopia 另有农舍日/夜、田垄、湿地、夜街、牧场神光、钓鱼、海滩、夜桥。

**缺口：** 官方静帧仍缺大量后期章节——伊斯特城火车坟场、永恒之塔外立面、黑潮/瘴气吞没的荒野、地震谷（Quake Valley）垃圾场的独立高清静帧（只有 IGN 实机视频，按要求未下视频）、大型 Boss 战、新坝夜景霓虹（只有地下/波特岛夜）、人群节庆、完整无 UI 的烹饪操作过程。Nintendo eShop / WeGame / Steam 中国没有比 Steam+Xbox+press kit 更多的新实机场景（eShop 多出来的是手绘 bundle/Octopia key art，已排除）。粉丝社区有伊斯特城与地牢补图，但官方已超过 25 张，故未收录。

**视觉语法：** 高密度现代像素 + 自制引擎 3D 光照，不是复古 8-bit 色块。固定 3/4 俯视，角色相对场景很小。环境用锈铁皮、电线、中英招牌、杂草和改装车辆做“舒适垃圾末日”。白天：赭黄/青绿、薄雾 bloom、软阴影；黄昏：整屏琥珀染色 + 石灯笼点光；夜晚：灯柱/火焰/橱窗做局部暖光源，暗部走蓝紫，火与霓虹有明显光晕。室内用锥形聚光、冷暖分区（如车厢暖厨房 vs 冷卫生间）。战斗 HUD：左下角色头像+心心+弹药，右上盐计数。
